# Nosivad Wiki Static Site

This folder contains the no-build player wiki for the Nosivad Legends of Aria shard.

Open `index.html` in a browser to preview it locally. The site can later be copied to any static host.

## Structure

- `index.html` - wiki landing page
- `whats-new.html` - recent live shard updates
- `getting-started.html` - first-hour guide for Eldeir Village
- `adventurer-levels.html` - player levels and grades
- `skills-stats.html` - skill and stat caps, vitality, and crafting
- `magic.html` - magic schools, spellbooks, summons, and travel
- `regional-events.html` - dynamic regional objectives
- `rifts.html` - standard planar rifts
- `breach-gates.html` - dungeon-style breach gates
- `world-bosses.html` - rare world boss events
- `creatures.html` - enemy rarity and creature source overview
- `loot-relics.html` - dynamic loot, graded gear, and relics
- `shrines-lore.html` - god shrines and lore
- `bounties.html` - bounty board contracts
- `reference.html` - terms and editor notes
- `assets/site.css` - shared styling
- `assets/site.js` - navigation highlighting and simple search

When adding a page, also add it to the `pages` array in `assets/site.js`.

Additional guides: professions, Vocation Renown, pets and companions, story, town renown, and markets and crafting.
